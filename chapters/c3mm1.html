What’s in a Name?

Counting letters in names

☆☆☆Best score 0

📖 What you will learn

In Class 3, everyone writes their name on a shiny name-tag. Whose name is the longest? Whose is the shortest? Let’s count letters together! ✏️

Names are made of letters — and letters can be counted! Compare name lengths and arrange names from short to long.

  • Count the letters in any name to find its length.
  • The name with the most letters is the longest.
  • Names with equal letters are the same length.
  • Arrange names in order — shortest first, longest last.
